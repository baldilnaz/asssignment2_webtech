## User Journeys

### Journey 1 — Learn About Arai
1. Open the Home page.
2. Read the short introduction to Arai Restaurant.
3. Open the About page.
4. View information about the restaurant, event halls, gatherings, parking, and contact details.

### Journey 2 — Explore the Menu
1. Open the Menu page from the navigation bar.
2. Browse the available food and drink categories.
3. Read the event menu information.
4. Continue to the reservation section.

### Journey 3 — Request a Reservation
1. Open the Menu page.
2. Go to the Reservation section.
3. Enter contact information and choose a preferred contact method.
4. Select a date, time, event type, and preferred space.
5. Enter the number of guests and other reservation details.
6. Submit the reservation request.
